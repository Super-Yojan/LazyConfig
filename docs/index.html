Installation

Fig. 01 — Three steps

Everything is deployed through just, which symlinks each configuration from this repository into ~/.config. One command links the whole desk; each tool can also be linked alone.

01 / Prerequisites

You need git, neovim, fish, wezterm and just.

# macOS (Homebrew)
brew install just neovim fish wezterm fzf eza

# Ubuntu / Debian
sudo apt install git fzf fish
02 / Clone and activate

just all links every tool at once — nvim, fish, wezterm, aerospace, tmux, starship, eza, sioyek, zed, and more.

# back up anything you care about first
git clone https://github.com/Super-Yojan/LazyConfig.git
cd LazyConfig
just all

Individual recipes exist for each tool:

just nvim      # link only the Neovim config
just fish      # link only the Fish config
just wezterm   # link only the WezTerm config
03 / First launch

Open nvim. On first run, lazy.nvim bootstraps itself and installs every plugin from the lockfile — no manual steps required.

$ nvim
  ...lazy.nvim installs plugins on first launch...

The editor

Fig. 02 — System layout

The editor is a custom LazyVim build. It follows the standard LazyVim layout, so anything the LazyVim docs teach works here unchanged.

The layout

nvim/
├── init.lua              # bootstrap lazy.nvim
├── lazy-lock.json        # pinned plugin versions
├── lazyvim.json          # LazyVim extras
└── lua/
    ├── config/           # options, keymaps, theme
    └── plugins/          # plugin specs — edit freely

Each file in lua/plugins/ returns a plugin spec table. Add a new file and lazy.nvim picks it up on the next launch. lazy-lock.json pins exact versions, so every machine runs the identical editor.

What ships

Research-ready out of the box: VimTeX driven by Tectonic, obsidian.nvim and neorg for notes, image.nvim for inline visuals, and Telescope for navigation.

The github-nvim-theme colorscheme follows the macOS appearance, switching between dark and light as the system does.

Updating

# pull the latest config, then inside Neovim:
git pull
:Lazy update      # update plugins
:Lazy sync        # or install/clean in one step
:TSUpdate         # refresh treesitter parsers
:Mason            # manage LSP servers, formatters, DAP

Control systems

Fig. 03 — Two leaders

Space leads in Neovim; Ctrl+Space leads WezTerm's window layer. Pause after the leader — which-key lists every option.
