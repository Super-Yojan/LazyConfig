An industrial OS
for your terminal.

LazyConfig is a complete environment for high-performance engineering — a custom LazyVim build, Fish, WezTerm and more, deployed as symlinks with a single command.

$ git clone https://github.com/Super-Yojan/LazyConfig.git && cd LazyConfig && just all

⚠ WARNING: this replaces your existing configs for the managed tools. Back up ~/.config first.

01 — Installation

Deploy in three steps

Everything is managed through just, which symlinks each config from this repo into ~/.config.

[1] Install prerequisites

You need git, neovim, fish, wezterm and just.

# macOS (Homebrew)
brew install just neovim fish wezterm fzf eza

# Ubuntu / Debian
sudo apt install git fzf fish

[2] Clone and activate

# backup anything you care about first
git clone https://github.com/Super-Yojan/LazyConfig.git
cd LazyConfig
just all

just all links every tool at once: nvim, fish, wezterm, aerospace, tmux, starship, eza, sioyek, zed, and more. You can also link tools individually:

just nvim      # link only the Neovim config
just fish      # link only the Fish config
just wezterm   # link only the WezTerm config

[3] First launch

Open nvim. On first run, lazy.nvim automatically bootstraps itself and installs every plugin from the lockfile (lazy-lock.json) — no manual steps required.

$ nvim
  ...lazy.nvim installs plugins on first launch...
02 — The Editor

Neovim, the LazyVim way

The editor is a custom LazyVim distribution. The Neovim config lives in nvim/ and follows the standard LazyVim layout, so anything you learn from the LazyVim docs works here too. 

nvim/
├── init.lua              # bootstrap lazy.nvim
├── lazy-lock.json        # pinned plugin versions (reproducible)
├── lazyvim.json          # LazyVim extras / settings
└── lua/
    ├── config/           # options, keymaps, autocmds, theme
    └── plugins/          # your plugin specs — edit freely

plugins/ is yours

Each file in lua/plugins/ returns a plugin spec table. Add a new .lua file and lazy.nvim picks it up on the next launch.

Reproducible

lazy-lock.json pins exact plugin versions, so every machine gets the identical editor.

Follows your macOS theme

The github-nvim-theme colorscheme auto-switches between dark and light when macOS appearance changes.

Research-ready

Ships with VimTeX (Tectonic / XeLaTeX), obsidian.nvim, neorg and image.nvim for inline visuals.

Updating

# pull the latest config, then inside Neovim:
git pull
:Lazy update      # update plugins
:Lazy sync        # or install/clean in one step
:TSUpdate         # refresh treesitter parsers
:Mason            # manage LSP servers, formatters, DAP
03 — Control Systems

Keybindings

All bindings follow the LazyVim conventions: Space is the leader in Neovim, and Ctrl+Space leads WezTerm's window layer. Type <Space> and pause — which-key shows every option.

KeyAction
<Space>lCompile LaTeX (VimTeX, continuous mode)
<Space>PPreview PDF — opens Sioyek with inverse search
<Space>lxClean LaTeX build artifacts
<Space>pEquation popup (Nabla)
<Space>ffFind files (Telescope)
<Space>eFile explorer (neo-tree)
<Space>/Grep across the project
WezTerm (Ctrl + Space)Action
Leader + \Split horizontally
Leader + -Split vertically
Leader + h/j/k/lMove focus (Vim style)
Leader + wWorkspace / session manager
Leader + zToggle pane zoom
